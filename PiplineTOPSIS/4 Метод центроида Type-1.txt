АЛГОРИТМ: Type1-Centroid
ВХОД: Взвешенная Type-1 матрица T[n][m] (треугольные числа)
ВЫХОД: Матрица решений C[n][m]

ФУНКЦИЯ ВЫПОЛНИТЬ_TYPE1_CENTROID(T):
    n ← РАЗМЕР(T)
    m ← РАЗМЕР(T[0])
    C ← НОВЫЙ_МАССИВ[n][m]
    
    ДЛЯ каждой альтернативы i от 0 ДО n-1:
        ДЛЯ каждого критерия j от 0 ДО m-1:
            triangular_number ← T[i][j]  // (a, m, b)
            a, m_val, b ← triangular_number
            
            // Центроид треугольного нечёткого числа
            centroid ← (a + m_val + b) / 3
            
            C[i][j] ← centroid
    
    ВЕРНУТЬ C
