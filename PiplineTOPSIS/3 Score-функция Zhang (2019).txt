АЛГОРИТМ: IVIFS-Score-Zhang
ВХОД: Взвешенная IVIFS матрица W[n][m]
ВЫХОД: Матрица решений S[n][m]

ФУНКЦИЯ ВЫПОЛНИТЬ_SCORE_ZHANG(W):
    n ← РАЗМЕР(W)
    m ← РАЗМЕР(W[0])
    S ← НОВЫЙ_МАССИВ[n][m]
    
    ДЛЯ каждой альтернативы i от 0 ДО n-1:
        ДЛЯ каждого критерия j от 0 ДО m-1:
            ivifs ← W[i][j]
            τ_min, τ_max ← ivifs[0]
            υ_min, υ_max ← ivifs[1]
            
            // Обобщённая probability-based функция Zhang (2019)
            // S = (τ⁻ + τ⁺ - υ⁻ - υ⁺ + (1 - τ⁺ - υ⁻)/2)/2
            score ← (τ_min + τ_max - υ_min - υ_max + (1 - τ_max - υ_min)/2) / 2
            
            S[i][j] ← score
    
    ВЕРНУТЬ S
