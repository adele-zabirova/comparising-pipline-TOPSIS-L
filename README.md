# comparising-pipline-TOPSIS-L
Study of defuzzification methods in fuzzy algorithms of the TOPSIS family on the results of ranking alternatives: an experimental comparison of defuzzification methods in the TOPSISort-L method.

# About 
This repository presents a new prototype for experimental comparison of defuzzification methods in the TOPSISort-L method in Python and  examples for testing these tools.

The prototype was implemented as part of Adel R. Zabirova's research project on "Decision-Making Methods" at the Institute of Computer Science and Cybersecurity at SPbPU.
